## 🧭 How to use this repository

1. **Watch the episode** — it explains *why* and shows *what it looks like*.
2. **Read the guide** in [`docs/`](docs/) — the same topic, slower, with tables, diagrams and the details the video skips.
3. **Try it yourself** — every guide has two levels: *no install* (a browser and a chat) and *for the curious*
   (a local model with [Ollama](https://ollama.com) and the scripts in [`episodes/`](episodes/)), always with a scripted
   path **and** a separate manual path.

Every number in the videos comes from a real measurement on a laptop, not from a slide deck. The scripts that produced
them are here, so you can check them — and get your own numbers.
